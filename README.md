# PNW Adventure

A personal weekend/adventure dashboard for the Pacific Northwest.

## Structure

- `index.html` — site shell
- `styles.css` — site styling
- `app.js` — renders the current weekend brief grouped by activity
- `data/current-week.json` — current weekend recommendations
- `data/archive/` — dated weekly snapshots

The weekly brief is designed to be updated automatically from ChatGPT research and then published through GitHub Pages.
